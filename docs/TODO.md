## 11. 验收指标

### 低风险场景

- [ ] 显存降低至少 50%。
- [ ] 业务质量下降不超过 1 个百分点。
- [ ] P95 延迟降低至少 20%。
- [ ] 吞吐提升至少 20%。

### 中风险场景

- [ ] 显存降低至少 30%。
- [ ] 业务质量下降不超过 0.5 个百分点。
- [ ] 金额、利率、日期字段准确率不低于冻结基线。
- [ ] 高风险回归集无新增关键错误。

### 高风险场景

- [ ] 优先使用 INT8、BF16/FP16 或经过验证的混合精度。
- [ ] 政策、金额、利率和期限关键样例无新增错误。
- [ ] 模型、配置、环境和评测资产均可追溯。
- [ ] 支持完整回滚。

## 12. 风险与依赖

| 风险 / 依赖 | 影响 | 应对措施 |
|---|---|---|
| 冻结基线仍只有 `37.15%` 准确率 | 量化差异可能被基线错误掩盖 | 必须按题型和业务错误分层比较 |
| 校准集不能代表业务分布 | 量化后质量结论失真 | 请求上游补充样本，不在优化阶段生产业务数据 |
| INT4 引入数字错误 | 金融业务不可接受 | 保护敏感层，升级到 INT8/BF16/FP16 |
| 剪枝未命中真实 kernel | 无实际加速 | 用 profiler 验证 kernel，不只检查稀疏率 |
| 后端不支持量化格式 | 模型无法部署 | 分别维护 NVIDIA 和昇腾候选配置 |
| 算子回退到高精度 | 延迟和吞吐不达标 | 保存 profiler、算子和后端日志 |
| 昇腾资源缺失 | 第 10 章无法启动 | 先完成 NVIDIA 主线，保持接口与配置可移植 |
| 版本或指标口径不一致 | 结果不可复现 | 锁定环境、模型、数据、配置和评测入口 |
